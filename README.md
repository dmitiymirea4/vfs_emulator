# Практическая работа №1. Эмулятор оболочки ОС
**Дисциплина:** Конфигурационное управление  
**Вариант:** №23  

## 1. Общее описание
Программа представляет собой графический GUI-эмулятор терминала, работающий с виртуальной файловой системой в памяти, загружаемой из XML.

## 2. Настройки и команды
* Параметры CLI: `--vfs`, `--script`, `--config`.
* Команды: `ls`, `cd`, `tail`, `who`, `clear`, `cp`, `rm`, `vfs-load`, `exit`.

## 3. Запуск
```bash
python src/main.py --config config.xml
```

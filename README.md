# Практическая работа №1. Эмулятор оболочки ОС
**Дисциплина:** Конфигурационное управление  
**Вариант:** №23  

## 1. Общее описание
Программа представляет собой графический GUI-эмулятор терминала на базе библиотеки `tkinter`. Эмулятор работает с виртуальной файловой системой (VFS) в оперативной памяти, которая инициализируется из XML-образа. Настройки путей к VFS и стартовому скрипту автоматизации считываются из конфигурационного файла `config.xml`.

## 2. Настройки и команды

### Параметры запуска
* Приложение принимает один обязательный аргумент — путь к конфигурационному файлу XML.
* Пример запуска: `python src/main.py config.xml`

### Поддерживаемые команды
1. `ls` — вывод содержимого текущей виртуальной директории.
2. `cd <путь>` — смена текущего рабочего каталога в VFS.
3. `tail <файл>` — вывод последних 10 строк указанного файла.
4. `who` — вывод имени текущего пользователя ОС.
5. `clear` — очистка текстового поля терминала.
6. `cp <источник> <приемник>` — копирование файла внутри VFS в памяти.
7. `rm <файл>` — удаление файла из структуры VFS.
8. `vfs-load <путь>` — динамическая загрузка нового XML-образа VFS.
9. `exit` — корректное завершение работы эмулятора.

## 3. Сборка и запуск проекта

### Требования
* Python 3.10+
* Зависимости: стандартная библиотека (`tkinter`, `xml.etree.ElementTree`)

### Быстрый запуск
```bash
# Для Windows
run.bat

# Для Linux / macOS
chmod +x run.sh
./run.sh
```

### Запуск модульных тестов
```bash
python -m unittest discover tests/
```

## 4. Примеры использования (Результаты работы)

### Сессия интерактивного режима
При успешном запуске эмулятор автоматически считывает файл `script.sh` и выводит результат выполнения начальных команд, после чего переходит в GUI-режим ожидания ввода пользователя:
```text
vfs_emulator:/$ who
dmitry
vfs_emulator:/$ ls
home/  etc/  readme.md
vfs_emulator:/$ cd home
vfs_emulator:/home$ exit
```

### Обработка ошибок в VFS
Если запрашиваемый файл или путь отсутствуют в XML-структуре, эмулятор выведет соответствующее уведомление:
```text
vfs_emulator:/\$ cd unknown_folder
Директория не найдена
vfs_emulator:/\$ tail nonexistent.txt
Файл не найден
```
